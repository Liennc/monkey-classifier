# Monkey Classifier

## Описание проекта

Monkey Classifier — это проект по классификации изображений обезьян с использованием сверточной нейронной сети ResNet18 и технологии transfer learning.

Проект позволяет:

* классифицировать изображения обезьян по видам;
* находить похожие изображения с использованием embeddings и FAISS;
* запускать обучение модели через DVC pipeline;
* использовать веб-интерфейс на Streamlit.

В проекте используется собственный датасет изображений обезьян, собранный и очищенный вручную.

# Dataset

Датасет состоит из 907 изображений обезьян 6 различных видов.

Классы:

* Ateles_geoffroyi
* Cebus_imitator
* Gorilla_beringei
* Macaca_fascicularis
* Pan_troglodytes
* Pongo_pygmaeus

Изображения были собраны вручную из открытых источников и очищены от нерелевантных данных.

---

# Модель

В проекте используется архитектура ResNet18.

Был применен transfer learning:

* использовалась pretrained модель, обученная на ImageNet;
* замораживались pretrained слои;
* обучался последний классификационный слой под задачу классификации 6 видов обезьян.

---

# Similarity Search

Дополнительно реализован поиск похожих изображений.

Для этого:

* из модели удаляется последний classification layer;
* изображения преобразуются в embeddings размерности 512;
* embeddings сохраняются в embeddings.pt;
* поиск ближайших изображений выполняется через библиотеку FAISS.

После загрузки изображения пользователь получает:

* предсказанный класс;
* 5 наиболее похожих изображений.

# Обучение модели

Обучение выполняется через DVC pipeline.

Запуск обучения:

```bash
 dvc repro
```

Гиперпараметры находятся в файле:

```text
params.yaml
```

После обучения сохраняются:
* metrics.json

---

# Запуск Streamlit приложения

```bash
streamlit run app.py
```

После запуска откроется веб-интерфейс для загрузки изображений.
